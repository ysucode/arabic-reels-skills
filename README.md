# سكلز Claude Code للأنميشن العمودي

سكلز لـ [Claude Code](https://claude.com/claude-code) أستخدمهم أصنع بهم ريلز وفيديوهات تيك توك بالعربي.

| السكل | وش يسوي |
|---|---|
| [`رواية`](skills/رواية/SKILL.md) | يحوّل قصة حقيقية أو ريل مرجعي إلى فيلم أنيميشن عمودي بلقطة واحدة بدون قص: قرارات، تحقق من المصادر، نص، ستوريبورد بإطارات حقيقية، صوت وموسيقى، رندر 60 إطار. |
| [`انمي`](skills/انمي/SKILL.md) | يصنع ريل أنميشن 60 ثانية بمقاطع Seedance من رفرنس ستايل: كاركتر شيت، ستوريبورد، كيفريمات، مقاطع، ثم تجميع. |
| [`نبرة`](skills/نبرة/SKILL.md) | يوزّع نبرة صوت الراوي على السكربت بوسوم ElevenLabs v4 (حماس، هدوء، همس، وقفات) بحذر وبدون مبالغة، قبل توليد الصوت. |
| [`ipad_code`](skills/ipad_code/SKILL.md) | يخلي الآيباد يشتغل ككمبيوتر قوي عن طريق جلسات Claude Code السحابية: رندر Blender بـ Cycles، ونص عربي على الفيديو، وتصميم صوت، وتجميع، ومزرعة رندر من أجهزة سحابية متوازية. |

كل خطوة فيها وقفة يقرر فيها المستخدم، والسكل ما يتجاوزها.

## التركيب

انسخ مجلدات السكلز إلى مجلد سكلز Claude Code:

```bash
cp -r skills/رواية skills/انمي skills/نبرة skills/ipad_code ~/.claude/skills/
```

على الآيباد أو لأي شخص جديد: افتح جلسة Claude Code على مشروعك وأرسل هذي الجملة، وClaude يكمل الباقي:

> نزّل هذا الملف بـ curl واقرأه كامل، ثم نفذ اللي فيه خطوة خطوة: https://raw.githubusercontent.com/ysucode/arabic-reels-skills/main/skills/ipad_code/START.md

## المتطلبات

- Claude Code
- Python 3 وNode.js وffmpeg
- حساب ElevenLabs لتوليد الصوت والموسيقى (المفتاح `ELEVENLABS_API_KEY` في ملف `.env` داخل مجلد المشروع)
- متصفح Chromium من Playwright لرندر الإطارات

مجلد العمل الافتراضي `~/content-studio`، وتقدر تغيّره بمتغير البيئة `STUDIO_DIR`.

## ملاحظات

- السكلز كُتبت وجُرّبت على ويندوز، فبعض الأوامر في السكربتات تفترض مسارات ويندوز (مثل `LOCALAPPDATA`).
- تعتمد على سكلز أخرى لازم تكون عندك: `watch` لقراءة الفيديوهات المرجعية، و`virality` لقواعد الجملة الخاطفة، وأدوات تحليل الإيقاع في `onetake`. رخصة `onetake` غير تجارية، فاقرأها قبل أي استخدام تجاري.
- موسيقى Eleven Music لها شروط حسب خطتك. تأكد منها قبل النشر.
- هذا المستودع بدون ملف رخصة بعد، فكل الحقوق محفوظة لين يُضاف.
